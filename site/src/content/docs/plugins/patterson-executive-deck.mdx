Patterson executive deck is the formal register of the deck family: an editorial navy cover, key takeaways, a breakdown matrix, requirements, build outputs, and benefits slides. It's denser and more structured than the standard deck — built for boards, leadership teams, and formal readouts rather than general presentations.

Reach for it when the audience is the ELT, a board, or a steering committee, and the content is a decision or a status that needs to be argued in one page per question. Every slide carries a running footer with a per-slide metadata row — arc, speaker, date — that stays live as the deck evolves, and `data-tweak` attributes mark the fields meant to be personalized per delivery.

The editorial register is deliberate: terse, declarative, evidence-first, one question answered per slide. The executive-deck-builder agent distills a brief straight into that shape — takeaways, matrices, and requirement tables — rather than writing narrative slides that need to be cut down later.
