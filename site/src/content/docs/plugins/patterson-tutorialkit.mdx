**Tag:** Scaffolder

Patterson tutorialkit brands TutorialKit, the Astro-based framework for interactive, hands-on tutorials. It ships the canonical `theme.css` — every color a `--tk-*` variable TutorialKit reads natively — plus logo lockups, a runnable Astro-and-UnoCSS starter, and a static preview page that renders entirely from those same variables.

Reach for it whenever the deliverable is training content someone works through, not just reads: onboarding material, an agent-tooling curriculum, a hands-on product walkthrough. The bundled starter already carries a 5-part, 18-lesson curriculum covering agent tooling — `AGENTS.md`, `CLAUDE.md`, skills, MCP, plugins, and marketplaces — with one lesson per Patterson plugin, so a new project can start from real content instead of a blank scaffold.

Theming an existing TutorialKit project is a two-file copy: `theme.css` and the logo SVGs. Change a token in `theme.css` and both the live app and the static preview update together, because neither one hardcodes a color. The tutorial-themer agent handles both the from-scratch and the brand-an-existing-project paths, and always writes content in Patterson's voice.

## What's inside

| Type | Name | What it does |
|---|---|---|
| Skill | `tutorialkit-theme` | Brand a TutorialKit project for Patterson Companies, or scaffold a new Patterson-branded TutorialKit starter. |
| Command | `/patterson-tutorialkit:brand-tutorialkit` | Apply the Patterson theme to a TutorialKit project, or scaffold the branded starter. |
| Agent | `tutorial-themer` | Patterson TutorialKit specialist — applies theme.css tokens, logos, and Patterson content voice. |
