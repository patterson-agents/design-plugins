## Trusted expertise. Unrivaled support.

Ten self-contained Claude Code plugins carry the Patterson Companies design
system into every kind of surface a team builds: marketing pages, decks, docs
sites, internal tools, and storefronts. Install one, and Claude scaffolds
on-brand — navy chrome, the 5px shape language, Proxima Nova, sentence case,
no emoji — without you touching a hex code.

Each plugin ships the same four parts: a **skill** Claude loads automatically
for relevant work, **commands** for explicit scaffolding, an **agent** you can
delegate to directly, and a `ds/` snapshot of every design-system file the
plugin needs, so it never depends on another plugin being installed.

## Install the marketplace

Add the catalog once, then install only the plugins you need. `patterson-brand`
is the foundation — install it first.

```
/plugin marketplace add patterson-agents/design-plugins
/plugin install patterson-brand@patterson-design
```
