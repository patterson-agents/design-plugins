Every plugin in this marketplace draws from the same source: one token set, one
component layer, one set of brand-compliant HTML specimens. Nothing here is
plugin-specific — change a token once in `patterson-brand`, and it propagates
to every `ds/` snapshot that carries it.

## Where the tokens live

Every plugin except `patterson-starlight` and `patterson-vitepress` carries a
byte-identical copy of `ds/tokens/*.css` and `ds/styles.css`. The canonical
copy lives in `patterson-brand`; changing a shared value means re-copying it
into every other plugin's `ds/` and re-verifying with md5 — there is no shared
or symlinked source. That duplication is deliberate: each plugin installs and
works on its own, with nothing to resolve across plugin boundaries.
